Kaggle Dataset Cleaning Practice
Source: Kaggle, Cafe Sales - Dirty Data for Cleaning Training (by Ahmed Mohamed)

Description: A synthetic dataset of 10,000 retail sales transactions, 
built explicitly for data cleaning practice. 
It contains missing values across multiple data types, 
invalid entries (like "ERROR" or "UNKNOWN" text strings inside numerical columns), 
and date format inconsistencies. 
We will use a real Airbnb dataset for Python Part II but this dataset is ideal for practicing multiple cleaning steps.
